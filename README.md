# Architecture Without Architects, project page

Static project page for "Architecture Without Architects: How AI Coding Agents Shape Software Architecture" by Phongsakon Mark Konrad, Tim Lukas Adam, Riccardo Terrenzi and Serkan Ayvaz (SAGAI Workshop, IEEE ICSA 2026, arXiv 2604.04990). The page is served at https://aiml-sdu.github.io/architecture-without-architects-page/.

This repository holds the built static page only. The case study code is at https://github.com/phomarkon/vibe-architecting-case-study.
